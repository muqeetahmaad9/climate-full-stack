You have THREE ways to run this project:
  A) One-click BAT files (fastest for dev)
  B) Manual terminal commands (full control)
  C) Docker Compose (production-like, one command)

 OPTION A — ONE-CLICK BAT FILES  (recommended for Windows dev)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1 — Install Python packages (run ONCE):
    Open a terminal in  C:\Users\HP\Desktop\pakclim\backend
    Run:  pip install -r requirements.txt

  Step 2 — Install Node packages (run ONCE):
    Open a terminal in  C:\Users\HP\Desktop\pakclim\frontend
    Run:  npm install

  Step 3 — Double-click these two files (open each in a separate window):
    C:\Users\HP\Desktop\pakclim\start-backend.bat    ← starts on port 8000
    C:\Users\HP\Desktop\pakclim\start-frontend.bat   ← starts on port 3000

  Step 4 — Open browser:
    http://localhost:3000

 OPTION B — MANUAL TERMINAL  (full control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ── BACKEND (Terminal 1) ──────────────────────────────────────────

    cd C:\Users\HP\Desktop\pakclim\backend

    # Create virtual environment (run ONCE)
    python -m venv venv
    venv\Scripts\activate

    # Install dependencies (run ONCE)
    pip install -r requirements.txt

    # Set environment variables
    set JWT_SECRET=pakclim_ndma_weatherlens_secret_key_2024_xK9mP3qR7vL2nW8
    set JWT_EXPIRE_MINUTES=60
    set JWT_REFRESH_EXPIRE_DAYS=7
    set SQLITE_DB_PATH=C:\Users\HP\Desktop\pakclim\data\weather_data.db
    set ENVIRONMENT=development
    set RATE_LIMIT_AUTH=5
    set RATE_LIMIT_LIVE_API=30
    set RATE_LIMIT_DB_QUERY=60

    # Start the server
    uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

    Backend is running at:  http://localhost:8000
    Auto-reloads on file save (--reload flag)

  ── FRONTEND (Terminal 2) ─────────────────────────────────────────

 OPTION C — DOCKER COMPOSE  (production-like, requires Docker Desktop)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1 — Start Docker Desktop (must be running)

  Step 2 — Create .env file in  C:\Users\HP\Desktop\pakclim\.env
    Copy the contents from .env.example or paste this:

      JWT_SECRET=pakclim_ndma_weatherlens_secret_key_2024_xK9mP3qR7vL2nW8
      JWT_EXPIRE_MINUTES=60
      JWT_REFRESH_EXPIRE_DAYS=7
      NEXT_PUBLIC_MAPBOX_TOKEN=pk.eyJ1IjoibmVvYzIwMjMiLCJhIjoiY2x1aTBubHAwMjYzOTJqcGc2cGFhMHU2ciJ9.tFU9_qFCY02qCvfiPMPDUg
      ENVIRONMENT=production

  Step 3 — Open terminal in  C:\Users\HP\Desktop\pakclim

    # Build and start all 3 services (mongo + backend + frontend)
    docker compose up --build

    # To run in background (detached):
    docker compose up --build -d

    # To stop:
    docker compose down

    # To stop and delete all data:
    docker compose down -v

  Step 4 — Open browser:
    http://localhost:3000

  Docker starts in this order (with healthchecks):
    MongoDB (port 27017)  →  Backend (port 8000)  →  Frontend (port 3000)

 ENVIRONMENT VARIABLES — EXPLAINED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Variable                     | Value / Notes
  ─────────────────────────────┼──────────────────────────────────────
  JWT_SECRET                   | Any long random string (keep secret)
  JWT_EXPIRE_MINUTES           | Access token TTL  (default: 60)
  JWT_REFRESH_EXPIRE_DAYS      | Refresh token TTL (default: 7)
  SQLITE_DB_PATH               | Absolute path to weather_data.db
  NEXT_PUBLIC_MAPBOX_TOKEN     | Mapbox public token for the map
  BACKEND_URL                  | http://localhost:8000 (dev) or
                               | http://backend:8000  (Docker)
  ENVIRONMENT                  | development | production
  RATE_LIMIT_AUTH              | Max auth requests/min per IP (5)
  RATE_LIMIT_LIVE_API          | Max weather requests/min per user (30)
  RATE_LIMIT_DB_QUERY          | Max DB requests/min per user (60)
  MONGO_URI                    | mongodb://localhost:27017/pakclim

 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Problem: "Module not found" on backend start
  Fix:     pip install -r requirements.txt

  Problem: "Cannot find module" on frontend start
  Fix:     npm install  (inside frontend folder)

  Problem: Map does not load (blank or black screen)
  Fix:     Check NEXT_PUBLIC_MAPBOX_TOKEN is set correctly

  Problem: "weather_data.db not found"
  Fix:     Verify SQLITE_DB_PATH points to the correct .db file
           The DB file should be at  pakclim\data\weather_data.db

  Problem: Port 8000 already in use
  Fix:     netstat -ano | findstr :8000
           taskkill /PID <pid> /F

  Problem: Port 3000 already in use
  Fix:     netstat -ano | findstr :3000
           taskkill /PID <pid> /F

  Problem: Docker "no space left on device"
  Fix:     docker system prune -f
